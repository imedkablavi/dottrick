# Dottrick

DotTrick — Gmail dot trick generator. Create every dotted variant of a Gmail username (before @gmail.com). Multi‑language (AR/EN/TR, RTL), light/dark theme, animated UI, accessible. Copy or save .txt. Static (HTML/CSS/JS) for GitHub Pages/Netlify. Keywords: gmail, alias, i18n, rtl, generator.
